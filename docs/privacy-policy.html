Политика конфиденциальности

Приложение: «Nivkh Dictionary» (Нивхский словарь)
Дата вступления в силу: 14 сентября 2026 г.

Данная Политика конфиденциальности описывает, какие данные обрабатывает приложение «Nivkh Dictionary» (пакет com.aleksandrgenrikhs.nivkhdictionary, далее — «Приложение»), разработанное Александром Генрихсом (далее — «Разработчик»). Используя Приложение, вы соглашаетесь с условиями настоящей Политики.

1. Какие данные собирает Приложение

Приложение не требует регистрации или входа в аккаунт и не собирает персональные данные пользователей: имя, адрес электронной почты, номер телефона, геолокацию, контакты, фотографии, идентификаторы устройства и т. п.

Приложение не использует сервисы аналитики, рекламные SDK, системы отслеживания поведения пользователей (Firebase Analytics, AdMob и аналогичные) и не собирает данные о действиях пользователя внутри Приложения.

2. Как используются разрешения Приложения

Приложение запрашивает следующие системные разрешения:

  • Доступ в интернет (INTERNET) — используется для загрузки словарных статей (слов и переводов на нивхском, русском и английском языках) с сервера bibl-nogl-dictionary.ru.
  • Доступ к состоянию сети (ACCESS_NETWORK_STATE) — используется для проверки наличия подключения к интернету перед обновлением словарных данных.

Эти разрешения не используются для сбора, передачи или обработки персональных данных пользователя.

3. Хранение данных

Загруженные словарные статьи сохраняются локально на устройстве пользователя (в базе данных приложения) для последующей работы без подключения к интернету. Эти данные представляют собой исключительно содержимое словаря и не являются персональными данными пользователя.

4. Передача данных третьим лицам

Разработчик не передаёт, не продаёт и не предоставляет какие-либо данные пользователей третьим лицам. Приложение не использует сторонние рекламные сети, аналитические платформы или иные внешние сервисы, обрабатывающие данные пользователей.

5. Безопасность

Разработчик принимает разумные меры для защиты работы Приложения. Поскольку Приложение не собирает персональные данные, риски, связанные с их утечкой, минимальны.

6. Дети

Приложение подходит для пользователей всех возрастов и не содержит материалов, предназначенных исключительно для взрослых. Разработчик сознательно не собирает персональные данные детей.

7. Изменения в Политике конфиденциальности

Разработчик может время от времени обновлять данную Политику конфиденциальности. Актуальная версия всегда будет доступна по этой странице с указанием даты последнего обновления.

8. Контакты

По всем вопросам, связанным с настоящей Политикой конфиденциальности или работой Приложения, вы можете обратиться к Разработчику по адресу электронной почты: bibl-nogl@mail.ru.
